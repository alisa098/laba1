# Лабораторная работа № 1 — Lakehouse и бенчмарк

**Выполнила:** Зуева Алиса Алексеевна  
**Группа:** БИВТ-24-АЭ-2

## Цель работы

Развернуть локальное Lakehouse, выполнить ELT-преобразование данных и сравнить форматы хранения и алгоритмы сжатия по размеру файлов, времени записи и скорости выполнения агрегаций.

## Состав проекта

- `catalog/` — конфигурационные файлы каталога и создание warehouse.
- `ЛР-1__БИВТ-24-АЭ-2_Зуева Алиса Алексеевна__ЛР-1. Бенчмарк. Сравние размера, времяни записи, скорости выполнения агрегаций в Spark.docx` — отчёт по лабораторной работе.

## Реализованная работа

- Локальное Lakehouse на основе MinIO, Lakekeeper и Trino.
- Организация данных по слоям Bronze, Silver и Gold.
- ELT-преобразование данных TPC-H.
- Построение агрегированной таблицы для аналитики.
- Сравнение GZIP и ZSTD по размеру данных и времени выполнения.
- Проверка эволюции схемы и восстановления состояния таблицы.

Подробная методика, результаты измерений и выводы приведены в отчёте.
